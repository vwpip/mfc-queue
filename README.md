# Электронная очередь МФЦ

Командный учебный проект по дисциплине «Программная инженерия» в МАИ, 2026 год.

Система предназначена для выдачи талонов, управления очередью и вызова посетителей к окнам обслуживания.

## Мой вклад

- Подготовила спецификацию функциональных и нефункциональных требований к системе.
- Разработала диаграмму вариантов использования (UML Use Case) для посетителя и сотрудника МФЦ.
- Описала 9 сценариев использования: предусловия, триггеры, основные и альтернативные потоки, постусловия.

Программную реализацию выполняли другие участницы команды.

## Документация

В репозитории размещён отчёт по проекту. Моя работа представлена в разделах «Спецификация требований к программе» и «Этап проектирования».
